                        SECURITY IMPROVEMENTS SUMMARY
================================================================================

DEFENSE AGAINST ATTACKS:

Brute Force           → Rate limiting (5 attempts/15 min) + bcrypt cost 12
XSS Attacks           → Input validation (Zod) + CSP headers + httpOnly cookies
CSRF Attacks          → SameSite cookies + CORS explicit allowlist
Injection Attacks     → Parameterized queries + Input validation
DoS Attacks           → Rate limiting + 100KB payload limit
Algorithm Confusion   → Explicit HS256 verification + issuer/audience claims
Session Hijacking     → Refresh token rotation + IP tracking
MIME Type Sniffing    → X-Content-Type-Options: nosniff
Clickjacking          → X-Frame-Options: deny
Privilege Escalation  → Session validation + inactive account checks

                        ENVIRONMENT VARIABLES REQUIRED
================================================================================

MANDATORY SECRETS (Generate with: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")

JWT_ACCESS_SECRET          → 32+ byte secret for access tokens
JWT_REFRESH_SECRET         → 32+ byte secret for refresh tokens
DATABASE_URL               → Neon pooled connection string
DIRECT_DATABASE_URL        → Neon direct connection string (migrations)

REQUIRED CONFIGURATION

CORS_ORIGINS               → Comma-separated frontend domain(s)
PUBLIC_URL                 → Shortener domain URL
NODE_ENV                   → Set to "production"

OPTIONAL CONFIGURATION

LOG_LEVEL                  → info, debug, warn, or error (default: info)
JWT_ACCESS_EXPIRES_IN      → Access token expiry (default: 15m)
JWT_REFRESH_EXPIRES_IN     → Refresh token expiry (default: 7d)
COOKIE_SECURE              → true/false (auto: true in prod)
COOKIE_SAME_SITE           → lax/strict/none (default: lax)
NOT_ALLOWED_SLUG           → Reserved slugs (default: analytics,links,...)

================================================================================
                           QUICK START GUIDE
================================================================================

1. INSTALL DEPENDENCIES (Already done)
   cd apps/api
   pnpm install

2. GENERATE JWT SECRETS
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   (Run twice, save both outputs)

3. SET ENVIRONMENT VARIABLES (In Vercel project settings)
   NODE_ENV=production
   JWT_ACCESS_SECRET=[generated secret 1]
   JWT_REFRESH_SECRET=[generated secret 2]
   DATABASE_URL=[Neon pooled URL]
   DIRECT_DATABASE_URL=[Neon direct URL]
   CORS_ORIGINS=[your frontend domain]
   PUBLIC_URL=[your shortener domain]

4. RUN TESTS LOCALLY
   pnpm test
   pnpm check

5. DEPLOY TO VERCEL
   git push origin main
   (GitHub Actions CI runs automatically)

6. VERIFY PRODUCTION
   curl https://your-api.com/health
   (Should return: {"status":"ok","timestamp":"..."})
